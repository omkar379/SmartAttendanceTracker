\# Smart Attendance Tracker



A web-based attendance management system developed using Python, Django and MySQL.



\## Technologies Used

\- Python

\- Django

\- MySQL

\- HTML, CSS, JavaScript

\- QR Code



\## Features

\- Student and Teacher Login

\- QR Code Attendance

\- Automatic Attendance Percentage

\- Low Attendance Alerts

\- Attendance Reports

\- Attendance History



\## Requirements

\- Python 3

\- MySQL Server



\## Installation



1\. Download or clone this project.

2\. Create a virtual environment:

&#x20;  python -m venv venv



3\. Activate the virtual environment.



4\. Install packages:

&#x20;  pip install -r requirements.txt



5\. Create a MySQL database and configure your local environment variables using .env.example.



6\. Run migrations:

&#x20;  python manage.py migrate



7\. Create admin:

&#x20;  python manage.py createsuperuser



8\. Start server:

&#x20;  python manage.py runserver



9\. Open:

&#x20;  http://127.0.0.1:8000/
